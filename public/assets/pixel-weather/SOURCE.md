# Pixel 天气图标来源

13 个静态天气 PNG 原样提取自用户提供的 `pixel-icon-provider-v4.apk`，未修改像素或透明通道。所有图片都是 256×256；合计 129,647 字节。

- 包名：`org.breezyweather.pixeliconprovider`
- 版本：`4.0`（versionCode 4）
- APK SHA256：`a63e7289762a72231b68aff246f2811267219395123fc24431aeadd32e1c65e5`
- 解码：apktool 2.11.1，仅静态解码，没有运行 APK。
- 每张 PNG 的原始 APK 成员路径与 SHA256、原包天气映射见 `manifest.json`。
- `preview.png` 是缩略核对图；实际使用时应引用各张原图。

天气名称与资源名来自原包 `res/xml/drawable_filter.xml`，并非仅凭文件名推测。昼夜使用不同图的类别为晴天与少云/多云；阴、雨、雪、雨夹雪、冰雹、雷暴、雾、霾、风使用同一张昼夜图。

原包中的雪与冰雹 PNG 像素相同；雾与霾 PNG 像素也相同，仍按原包分类保留不同语义文件名。未抽取动画分层、快捷方式背景或 Java 实现的太阳/月亮绘制器。

`manifest.json` 中的和风天气代码是重制版接入建议，原包本身没有声明和风代码。未知天气、沙尘、极热/极冷没有单独的图标，应保留通用回退及准确天气文字。

## 授权状态

APK 内没有单独命名的图标许可证文件，已检查的 XML 与目标 DEX 字符串没有建立图标再分发授权。包名、图标在 APK 中出现以及用户提供 APK 均不等于公开再分发许可。当前按用户要求用于自用重制测试；公开发行前需另外核实图标权利和授权范围。
