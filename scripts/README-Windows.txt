初音天气 · Reborn 0.3.6（服务端代理版）

请把 ZIP 完整解压到普通英文目录，再运行 Miku Weather Reborn.exe。
例如 D:\MikuWeatherReborn\
不需要管理员权限，不需要填写天气 API 密钥。

初音与天气气泡默认显示在屏幕右下角。
拖动初音：移动桌宠并保存位置。
点击初音或气泡：打开天气详情。
右键初音：切换城市、刷新、置顶、隐藏与退出。
“切换城市 / IP 定位”默认使用腾讯位置服务，通过公网 IP 推算城市。
只在主动点击后请求，应用不保存 IP，由你确认候选城市后选择。
天气请求使用所选城市的公开中心坐标，不后台定位、不记录轨迹。
托盘图标：单击显示初音，双击打开天气详情。

主题默认跟随所选城市的日出与日落：日出浅色、日落深色。
天气详情“偏好设置”可选择自动、浅色、深色或跟随系统，桌宠同步外观。
缺少日出日落数据时使用所选城市当地 6:00/18:00。
腾讯可看到请求端公网 IP；VPN、代理或运营商出口可能导致偏城。备用 Windows 系统定位仍会拒绝默认、IP、误差过大或旧结果。

本机 Codex 工作区中的运行目录曾触发 Electron 子进程创建失败。
如果点击无反应或提示加载失败，请先解压到工作区之外的普通英文目录。
诊断日志为 miku-startup.log，不需要关闭任何系统安全功能。

天气数据来自和风天气 https://www.qweather.com/
非官方重制自 https://github.com/lzcapp/MikuWeather_Windows
原许可证保留在安装包内，天气详情“关于重制版”可查看。

本公开包仅内置天气代理地址，不包含和风私钥或腾讯 Key。
服务通过 Cloudflare Worker 访问和风天气，IP 定位把请求端公网 IP 转交腾讯；不自行记录 IP。
角色与图标素材属于各自权利人，来源与许可说明随包保留。
