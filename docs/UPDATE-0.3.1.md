# 0.3.1 · 小组件外观、城市语言与应用更新

- Android 设置新增底板不透明度（0–100%，默认全透明）与小组件字号（100–140%，默认 110%）滑块，支持实时预览并保存。文字和初音始终清晰。
- 小组件左下角增加小刷新图标（48dp 点击区域），时间缩小并与温度分开。温度独立大字显示；左侧初音、右侧时钟、温度、日期及天气。小尺寸优先保留温度，隐藏次要城市行。点击初音刷新，点击文字区域打开应用。
- 城市名称、地区和国家跟随简体中文、繁體中文、English、日本語切换。查询严格匹配原城市 ID，保留坐标与时区，语言结果缓存 30 天。断网或服务未提供翻译时保留已知名称。
- 启动时检查 GitHub 稳定发布，检查间隔至少六小时；设置里可随时手动检查。Windows 桌宠启动也会检查并在托盘提示。检测更新不会自动退出应用或安装。
- Windows 点击“下载并安装更新”后下载官方 ZIP，验证大小与 SHA256，退出应用、备份被替换文件、替换并重新启动。原 AppData 设置保留，程序目录需要可写。
- Android 点击后下载 APK，验证 SHA256、包名、递增版本号及安装签名，再打开系统安装界面。首次可能需要允许来自本应用的安装，返回后再次点击安装即可。
- iOS 检测到更新后打开 IPA 下载页，仍需自行签名侧载；没有 WidgetKit 主屏幕扩展。

## 安装

0.3.0 及更早版本没有更新模块，需要先手动安装一次 0.3.1。Windows 完整解压 ZIP 到普通英文目录，Android 用同签名 APK 覆盖安装；iPhone 自行签名 IPA。之后 Windows 与 Android 可使用应用内更新。

## 验证范围

城市服务实测英语 Shenzhen、日语深セン市、繁体廣東省，天气接口正常。自动化测试覆盖城市 ID 和语言缓存、版本比较与发布附件校验、下载损坏/大小错误/异常重定向、透明度范围。Windows 临时安装目录实测 ZIP 路径拒绝、解压、替换、备份及无关文件保留。

浏览器模拟 Android 桥接验证了滑块保存与同步、四语言城市显示、更新成功/无新版/离线/安装许可分支及 360/430 像素布局。此检查不代替 Android 真实启动器或系统安装器验收。移动安装包由 GitHub Actions 编译；iPhone 尚未完成真机签名安装验证。
