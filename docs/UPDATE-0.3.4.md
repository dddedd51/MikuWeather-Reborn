# 0.3.4 · 刷新成功提示自动消失

小组件“更新成功”显示约 3 秒后自动清除，无需再次刷新或打开应用。短时广播接收任务会在计时结束后仅清理提示，避免触发新的天气请求。

清理前检查城市、刷新编号及提示时间，旧计时器不会清掉新一次刷新或错误提示。保存的成功状态在过期后也不再显示，防止进程重启时恢复旧提示。

新增定时回归测试，验证 3 秒前可见、3 秒后清除，以及连续刷新后的状态保护。原有城市完整行、外观选择、透明度及失败缓存行为保留。

从设置检查更新并安装 0.3.4。Android APK 沿用原签名；iPhone IPA 仍需自行签名侧载。Android 原生测试不代替 MIUI 真机复测。
