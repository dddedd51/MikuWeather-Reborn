# iPhone 天气小组件

需要桌面小组件时，选择文件名以 `iOS-unsigned.ipa` 结尾的包。重签时保留扩展，为主应用和小组件各分配一个属于同一团队的应用标识与描述文件。小组件标识应以主应用标识和一个点开头。两个目标都使用普通签名，无需启用 App Groups。工具只支持单个应用标识时，可选 `iOS-AppOnly-unsigned.ipa` 使用天气主应用。

1. 长按主屏幕，添加「初音天气」小组件，选择小、中或大尺寸。
2. 长按刚添加的小组件，进入「编辑小组件」，在「城市或配置码」里输入城市名，例如「深圳」。
3. 要精确指定同名地区、国外城市、华氏度、语言或主题，先在主应用选好城市和偏好，在设置内复制「小组件配置码」，粘贴到上述栏位。每个小组件独立设置，更换城市或偏好后可复制新码。

小组件在自己的沙盒内缓存天气，从既有天气服务获取数据。iOS 安排刷新时机，缓存最多保留 24 小时。未设置城市或输入无法识别时，小组件会提示编辑城市。
