# 0.3.2 · 小组件留白与圆角修复

MIUI 实机截图显示，0.3.1 的文字紧贴右侧遮罩，底部城市名进入圆角区域。原因是原先只给遮罩和内容的共同父层留边距，没有单独设置内容内边距；背景位图还会在宽版组件中横向拉伸圆角。

- 宽版内容左右各留 18dp、上下各留 14dp；紧凑版左右各留 12dp，较矮组件上下各留 10dp。
- 时间、温度及天气文字按扣除内边距后的实际预算适配，保留温度大字、时间小字分行。
- 背景按组件宽高比例绘制，圆角固定在约 22dp，不再随宽度拉伸成大椭圆角。
- 左下角刷新按钮、透明度与字号设置、四种语言和应用更新功能继续保留。

0.3.1 用户可在设置中检查更新并安装。Android 需要在系统安装界面确认；更新后点击一次小组件刷新。更早版本需要手动安装。iPhone 仍需重新签名侧载。

验证包括横向/紧凑/较矮尺寸、最大字号和长温度的布局预算回归，以及 Android 编译、单元测试、lint 和安装包签名校验。设置预览检查不能代替 MIUI 桌面实机复测；修复依据为用户提供的原版实机截图。
