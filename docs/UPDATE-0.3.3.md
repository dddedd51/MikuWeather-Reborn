# 0.3.3 · 城市完整显示、外观同步与刷新反馈

- 城市名改为独立底部行，先保留完整文字行高；上方时间、温度、日期和天气按 Android 实际测量结果适配。测量包含中文后备字体和字体内边距，替代仅靠字号比例估算。
- 小组件跟随用户选择的浅色、深色、跟随系统或自动外观；只有自动模式按城市日出日落切换。透明度保持当前设置。
- 手动刷新在左下角按钮上方显示等待、正在更新、更新成功、没有网络、失败或稍后重试等状态；提示不占城市名的位置。
- 手动刷新会向天气服务请求当前数据；失败保留已有缓存。重复点击会合并，旧请求不会覆盖新请求的反馈状态。

新增 Robolectric Android 原生 View 测量与绘制检查，覆盖中英日文字、不同密度、最大字号、长温度和启动器略微压缩高度的情况，检查每一行的完整可见性。原生测试使用标准 Android 字体，不等同于 MIUI 真机；仍需要实机复测。

0.3.1/0.3.2 用户可在设置中检查更新安装，Android 需系统安装确认。iPhone IPA 仍需自行签名侧载。
