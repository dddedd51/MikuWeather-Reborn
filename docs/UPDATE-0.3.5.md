# 0.3.5 · 修复 Windows 应用内更新

修复 PC 点击更新后关闭应用却没有完成升级的问题。路径边界检查使用真实的 Windows 分隔符；Windows PowerShell 5.1 明确按 UTF-8 读取配置，支持中文、空格和引号目录。

退出应用前，确认辅助程序完成检查和备份。替换后逐文件校验，失败时恢复旧文件、清理本次新增文件并重新启动旧版。结果写入应用数据目录的 update.log，重新打开时提示失败原因。

**旧版更新器也存在此错误，因此这一次请下载 Windows ZIP，退出应用后完整解压覆盖原目录，再启动新版。** 城市和偏好设置保存在应用数据目录。之后可继续使用设置中的“下载并安装更新”。

验证包括真实 Windows PowerShell 5.1 中的中文目录覆盖、等待原进程退出、启动新版、只读目录拒绝和中途失败回退，以及下载校验和辅助进程启动失败检查。

Android 与 iOS 同步版本号，保留 0.3.4 的小组件行为。iPhone IPA 仍需自行签名侧载。
