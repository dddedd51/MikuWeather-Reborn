# 0.3.6 Android 腾讯 IP 定位

城市选择页新增“IP 定位当前城市 · 腾讯位置服务”，与原有 GPS / 系统定位分别提供按钮。IP 定位无需 Android 位置权限，仅主动点击后请求；返回网络出口的大致城市，用户确认候选后才切换城市。

公开 APK 只包含公开代理网址，腾讯 Key 和签名留在服务端。应用不保存 IP，设备 GPS 坐标不上传。VPN、代理和运营商网络出口可能造成城市偏差；服务无覆盖时可手动搜索城市。

请求在完成、取消、退出前台或 12 秒超时后结束。重复点击不会启动重叠请求，取消后的迟到响应不会切换城市。无网络、服务不可用和异常响应均显示可重试提示。新增说明与错误提示提供简体中文、繁体中文、英语和日语。

Android 版本号为 0.3.6，构建号为 12。与维护者此前 APK 使用相同签名，支持覆盖安装并保留城市及小组件设置。
